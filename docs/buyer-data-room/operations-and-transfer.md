# Operations and transfer checklist

Last reviewed: 2026-07-19

## Before diligence

- [ ] Record the exact legal owner and deal perimeter.
- [ ] Create a credential inventory without copying secrets into this repository.
- [ ] Confirm two independent administrators and 2FA recovery for every material account.
- [ ] Produce a current architecture diagram and monthly operating calendar.
- [ ] Run and document a cold-backup restoration test.
- [x] Google OAuth consent app is in production (verified 2026-08-27); the local token refreshed successfully and the scheduled Search Console workflow last completed successfully on 2026-08-25.

## Transfer sequence

- [ ] Sign asset-purchase agreement and IP assignments.
- [ ] Agree privacy/data-transfer mechanism for newsletter and analytics data.
- [ ] Transfer/push domain and reproduce DNS with rollback records retained.
- [ ] Transfer repository or grant purchaser ownership; rotate all deployment secrets.
- [ ] Transfer Netlify site/team and verify the production domain/build output.
- [ ] Add purchaser admins to GA4, GSC, Bing Webmaster Tools and relevant tag accounts.
- [ ] Move email/newsletter configuration and preserve unsubscribes/suppression obligations.
- [ ] Replace Anthropic, Resend and other billing credentials with purchaser-owned credentials.
- [ ] Transfer social properties where platform terms permit.
- [ ] Update website controller, contact, copyright, terms and privacy information.
- [ ] Run smoke tests: DNS/TLS, redirects, forms, checker, email confirmation, analytics and sitemap.
- [ ] Revoke seller access only after readback and rollback window.

## Platform caveat

Do not promise that an AdSense publisher account or any personal account can be sold. Record the platform's current transfer/re-verification route at the time of a transaction and describe the asset as the website/ad inventory unless the platform confirms otherwise.
