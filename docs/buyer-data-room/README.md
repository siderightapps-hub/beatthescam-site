# Beat the Scam buyer data room

Status: working structure, created 2026-07-19. This repository contains the non-confidential index and operational evidence. Sensitive exports, credentials, personal data, contracts, invoices and tax documents must stay in a separately access-controlled deal room.

## Purpose

The data room lets a prospective purchaser verify what is being acquired, how it performs, what it costs and how control can be transferred. Claims belong here only when supported by a dated platform export, invoice, registration record, repository history or signed agreement.

## Disclosure rules

- Use read-only or redacted evidence during early diligence.
- Never commit API keys, recovery codes, passwords, subscriber records or identity documents.
- Give personally identifiable information only where lawful, necessary and covered by deal terms.
- Date every export and preserve its platform, property/account identifier and reporting window.
- Distinguish verified facts from forecasts. Forecasts must state assumptions and must not be presented as valuation evidence.
- Record exclusions explicitly: personal accounts, non-transferable publisher accounts, unrelated SideRight Apps assets and any third-party licence that cannot be assigned.

The monthly KPI and P&L ledgers are in `analytics/commercial/`. Search and AI snapshots are in `analytics/search-ai/`.
